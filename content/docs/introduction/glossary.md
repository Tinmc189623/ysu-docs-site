文档里出现的名词，按首次可能遇到的顺序排。

## 内核

**YSU** — 网页渲染内核。把 HTML 与 CSS 变成可以交给 GPU 绘制的显示列表。

**Engine** — 内核门面，`src/engine.rs` 里的那个结构体。建实例、设视口、喂 HTML、取显示列表、按坐标做命中测试都从它走。十个模块也可以绕过它单独用。

**显示列表（`DisplayList`）** — 绘制阶段的产物，一串平台无关的绘制命令，外加目标画布尺寸。

## 解析

**记号（`Token`）** — 词法阶段的产物。七种：DOCTYPE、起始标签、结束标签、注释、CDATA 段、文本、输入结束。

**原始文本模式（`RawTextMode`）** — 决定标签内容按什么规则扫描。`Rcdata`（字符引用仍生效，如 `<title>`）、`Rawtext`（字符引用不生效，如 `<style>`）、`ScriptData`（额外处理 `<!--` 引起的转义状态）、`Plaintext`（其后全是文本）。

**CDATA 段（`Token::Cdata`）** — 同一个记号在两种上下文里处理完全不同。在外来内容里它是一段文本，在 HTML 内容里它是一次解析错误、按注释收场。词法器不知道自己在哪种上下文里，所以原样交出去让树构建判断。

**插入模式（`InsertionMode`）** — HTML 树构建的状态机。`src/html/tree_builder.rs` 按规范那套模式把记号流变成文档树。

**收养机构算法（adoption agency）** — 规范里处理交错的格式化元素那一段，比如 `<b>` 与 `<i>` 相互穿插的情形。

**寄养（foster parenting）** — 表格里遇到不该出现的内容时，规范要求把它放到表格**之前**，而不是塞在表格里。

**怪异模式（quirks mode）** — 缺少或写坏 DOCTYPE 时进入的兼容模式。树构建阶段记下这件事。

**外来内容（foreign content）** — SVG 与 MathML 的子树，标签名与属性有各自的调整规则，`src/html/foreign.rs` 管这块。

**字符引用** — 具名与数字两种，`src/html/references.rs` 负责查表。具名表在 `src/html/entities.rs`，两千多条，由 `tools/generate_entities.py` 从规范的 `entities.json` 生成，别手工改。

## 样式

**来源（`Origin`）** — 一条声明从哪来。三种，优先级从低到高：用户代理样式、作者样式、元素上的 `style` 属性。

**优先级（specificity）** — 选择器的权重。行内样式按零算，它靠来源区分，不靠权重。

**计算样式（`ComputedStyle`）** — 层叠与继承算完之后每个节点最终用到的属性值。它是布局的直接输入。

## 布局

**盒子种类（`BoxKind`）** — 十二种：块级盒、行内盒、行内块、弹性容器、列表项、文本、匿名块盒，以及表格容器、行组、行、单元格、标题五种表格盒。

**匿名块盒** — 块容器里混着行内级内容时，用没有对应元素的块盒把连续的行内内容包起来。

**行盒（`LineBox`）** — 一行内容所占的范围。

**行片段（`LineFragment`）** — 行盒里的一段，带位置、尺寸与基线。基线是文本片段用来摆字形的。

**布局上下文（`LayoutContext`）** — 布局需要的外部条件：视口宽高，以及根元素字号（`rem` 参照它）。

## 绘制与渲染

**绘制命令（`DrawCommand`）** — 六种：填充矩形、画边框、画文字、画图片、压裁剪、弹裁剪。

**裁剪（`PushClip` / `PopClip`）** — 把后续绘制限制在指定范围内，成对出现。

**字形图集（`GlyphAtlas`）** — 一张把用到的字形位图拼在一起的大纹理。文字渲染按坐标从图集里采样，而不是每个字形单独一张纹理。

**命中测试** — 按坐标找节点。两个入口：`Engine::element_at` 给出所在的盒子，`Engine::fragment_node_at` 能给到行内内容真正属于哪个节点——判断点在不在链接上要靠后者。

## 网络

**取回（fetch）** — `net::Client` 发一次请求拿回响应。响应里有最终地址、状态码、原因短语、重定向次数、正文与头部。

**字符集嗅探** — 正文怎么解码成字符串。`net::encoding` 的 `sniff` 先看 `content-type`，看不出来再按内容判断。
