# 快捷键

全套键盘操作。所有快捷键都挂在 Qt 的动作上、作用范围是整个窗口，不是某个部件。

## 标签页

| 按键 | 作用 |
| --- | --- |
| `Ctrl+T` | 新建标签页 |
| `Ctrl+W` | 关闭当前标签页 |
| `Ctrl+Tab` | 切到下一个标签页（循环） |
| `Ctrl+Shift+Tab` | 切到上一个标签页（循环） |

只有多于一个标签页时 `Ctrl+Tab` 才会动作，单标签页时按它没反应。

## 导航

| 按键 | 作用 |
| --- | --- |
| `Ctrl+L` | 聚焦地址栏并全选内容 |
| `Ctrl+R` / `F5` | 重新加载 |
| `Ctrl+H` | 回到起始页 |
| `Ctrl+O` | 打开本地文件（系统对话框） |
| `Alt+←` | 后退 |
| `Alt+→` | 前进 |
| `Ctrl+0` | 缩放回到 100% |
| `Ctrl+=` | 放大一步 |
| `Ctrl+-` | 缩小一步 |
| `F11` | 全屏切换 |

`Ctrl+L` 会顺手把地址栏内容全选，所以紧接着输新地址会直接覆盖，不用先清空。

`Alt+←` 在 Linux 上有时候会被窗口管理器吃掉。真按不动的话用工具栏上的后退按钮，或者检查一下 WM 的按键绑定。

## 滚动

| 按键 | 作用 |
| --- | --- |
| `PageDown` | 向下翻一页 |
| `PageUp` | 向上翻一页 |
| `Home` | 跳到顶部 |
| `End` | 跳到底部 |
| 滚轮 | 一格 40 像素 |
| 横向滚轮 | 左右滚动 |

翻页的量按视口高度算，所以窗口大小不同时翻的距离也不同。

## 地址栏里

地址栏是 Qt 的 `QLineEdit`，所以它的键位就是 Qt 的标准键位：

| 按键 | 作用 |
| --- | --- |
| `Enter` | 访问当前输入 |
| `Ctrl+A` / `Home` / `End` | 常规的文本编辑 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Esc` | 没有绑定动作 |

输入法走 Qt 的插件，装有 fcitx5 或 ibus 的 Qt 插件时能直接输中文，不需要改代码。

## 缩放的实际范围

一次缩放乘除 1.25。`Ctrl+=` 连按的范围：

```
100% → 125% → 156% → 195% → 244% → 305% → 381% → 477% → （到顶）
100% →  80% →  64% →  51% →  41% →  33% →  26% → （到底）
```

下限 25%，上限 500%，超出就夹住不动。工具栏中间的标签显示当前百分比。

## 没有绑定的键

`Ctrl+D`（书签）、`Ctrl+Shift+Delete`（清除数据）、`Ctrl+P`（打印）这些常见键位都没绑定——对应的功能还不存在。`Esc` 也不停加载，因为没有取消加载的接口。
